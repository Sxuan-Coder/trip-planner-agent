# 旅游规划Agent

- 目标是构建一个能处理分步任务的智能旅行助手。

1. 需要解决的用户任务定义为："你好，请帮我查询一下今天北京的天气，然后根据天气推荐一个合适的旅游景点。"
2. 要完成这个任务，智能体必须展现出清晰的逻辑规划能力。
3. 它需要先调用天气查询工具，并将获得的观察结果作为下一步的依据。
4. 在下一轮循环中，它再调用景点推荐工具，从而得出最终建议。

## 运行方式

本项目使用 [uv](https://docs.astral.sh/uv/) 管理 Python 环境和依赖。

**激活虚拟环境后运行：**
```bash
source .venv/Scripts/activate
python main.py
```

**或直接用 uv 运行：**
```bash
uv run python main.py
```
